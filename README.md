# Lead Tracker Chrome Extension

A simple Chrome extension for saving and managing potential leads directly from the browser.

## Features

- **Manually Add Leads:** Enter and save lead information manually.
- **Save Current Tab:** Capture and save the URL of the currently active browser tab using chrome API
- **Delete Leads:** Remove saved leads when they are no longer needed.

## Technologies Used

- HTML
- CSS
- JavaScript
- Chrome Extension APIs

## Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/Htoo-Eaindra-Tin/Lead-Tracker-Chrome-Extension.git
   ```

2. Open Google Chrome and navigate to `chrome://extensions/`.
3. Enable Developer mode.
4. Click **Load unpacked**.
5. Select the folder containing `manifest.json`.
